# NYC Taxi Data Analysis Using PySpark

## Project Overview
Analyzed NYC Yellow Taxi trip data using PySpark to perform data cleaning, large-scale data processing, and business analysis.

## Technologies Used
- Python
- Apache Spark / PySpark
- Spark SQL
- Pandas
- Matplotlib
- Google Colab
- Parquet

## Key Tasks
- Data exploration and quality checks
- Handling missing and unusual records
- Trip duration calculation and data cleaning
- Business analysis using PySpark and Spark SQL
- Lazy evaluation, caching, repartitioning, and coalescing
- Parquet data storage and validation
- Data visualization using Matplotlib

## Key Insights
- Cleaned records: **3,679,623**
- Average trip payment: **$29.22**
- Total recorded revenue: **$107.51 million**
- Busiest hour: **6 PM**
- Most common payment method: **Credit Card**

## Visualizations
- Trips by hour
- Revenue by payment type
- Trips by distance category
- Average payment by passenger count
- Revenue by hour
